Windows Update Repair Tool (C#)

Este aplicativo Windows Forms replica as funções principais do script batch original:

- Resetar componentes do Windows Update
- Executar SFC
- Executar DISM
- Apagar arquivos temporários
- Exibir logs das operações

Para usar:
1. Abra o projeto no Visual Studio.
2. Compile e execute como Administrador.
3. Clique nos botões para executar cada função.

Expanda conforme necessário para outras funções do script original.
